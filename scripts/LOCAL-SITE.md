# 本地网站常驻服务

访问地址：http://127.0.0.1:5173/

Windows 计划任务 `Xiaofeng-Local-Website` 在当前用户登录时启动隐藏的后台守护进程。
守护进程启动 Vite，固定绑定本机 5173 端口；服务器退出后 5 秒重试。
每 10 秒检查一次 HTTP，连续三次失败会重启本项目服务器。
计划任务无运行时长限制，允许电池供电；守护进程异常退出后每分钟重启。
命名管道锁避免重复启动。日志位于 `artifacts/local-site.log`，超过 2 MB 轮换。

另设每分钟无限重复的时间触发器：即使整个任务被终止（如退出码 0xC000013A），
仍会在下次触发时重新启动。任务运行期间忽略重复启动。

手动启动：运行 `scripts/start-local-site.ps1`，或在 Windows 任务计划程序中运行该任务。
取消登录自启动：在任务计划程序中禁用 `Xiaofeng-Local-Website`。

需要保留项目文件夹、node_modules，以及启动脚本中的 Node.js 运行时路径。
关闭电脑、尚未登录 Windows、端口被其他程序占用、删除项目或 Node.js 时不能保证访问。
服务只对本机开放；不会自动终止占用端口的其他程序。

已验证：HTTP 200；主动停止 Vite 后自动启动新进程并恢复 HTTP 200。
